# Contributing to AkiZentetsu

Thanks for helping shape this project. It is still at the idea stage, so proposals and small, focused improvements are welcome.

Before starting a larger change, open an issue to discuss the problem and your proposed approach. For a pull request, describe what changed, why it helps contributors, and how you checked it. Keep each PR focused enough to review.

AkiZentetsu should encourage genuine open-source work. Please don't add features that automate spam, fabricate contributions, or promise GitHub achievements that the project cannot guarantee.
